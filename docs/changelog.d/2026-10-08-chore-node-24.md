### Changed
- **Back to Node 24:** `.nvmrc` / `.node-version` → `24`, `engines.node` `>=26` → `^24`, and `@types/node` (catalog) 26.6.3 → 24.19.1 so the types match the runtime. `@types/node` is now also a direct devDependency of the root and `packages/ui`, since vite, vitest and commitlint otherwise auto-install it as a peer at the latest major (26). Dependabot now ignores `@types/node` majors so it doesn't propose 25+ again. README updated. *Why:* the project is standardising on Node 24 (the current LTS line) instead of following the latest release.
