### Removed
- **e2e in GitHub CI (`.github/workflows/ci.yml`):** The `e2e (app)` and `e2e (www)` jobs are gone, so CI only lints, typechecks and builds. Run the suites locally with `pnpm test:e2e`. `docs/e2e-architecture.md` and the e2e harness comments no longer describe CI as running them. *Why:* the suites ran on every push and PR, which kept CI slow for checks that are run locally anyway; projects built from Turbostack had each been removing the job by hand.
